1. Architecture Requirements

When syncing notes across partitioned edge clients, deterministic state convergence is non-negotiable. Standard Operational Transformation (OT) requires a centralized coordination authority, which breaks our offline-first and end-to-end zero-knowledge storage invariants. Consequently, every mutation is modeled as an append-only EventLog tracked by causal order via a monotonic VectorClock.

info CRYPTOGRAPHIC INVARIANT

Payload contents must be symmetrically encrypted prior to peer dissemination. The causal metadata (vector clocks and document entity UUIDs) remains transparent to allow relay topology gossip without plaintext exposure.

data_object types/sync.ts 
type DocumentState = {
  id: string;
  version: number;
  localChanges: Delta[];
  vectorClock: Record<string, number>;
  checksum: Uint8Array;
};

Operational Tenets

  • •
    Deterministic Replay: Concurrent edits evaluate through Lamport timestamps to resolve concurrent writes consistently across all nodes.
  • •
    Delta Compression: Periodic compaction runs bundle intermediate delta events into squashed base checkpoints to preserve disk quota.
  • •
    Local Ephemeral Buffers: Uncommitted keystrokes write into IndexedDB memory buffers instantly before socket broadcast attempts.

Further benchmarking against 100,000 synthetic operations demonstrates sub-5ms merge latency on baseline client devices. Next step involves integrating differential compression for rich media blobs...
