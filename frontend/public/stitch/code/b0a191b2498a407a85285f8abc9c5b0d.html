Legacy Architecture RFC (Draft)

status: deprecated author: sys-core

This Request for Comments details the retirement sequence of the primary Node v1 routing gateway and associated in-memory queue dispatchers. Components marked for deprecation are currently non-functional under the zero-trust cluster perimeter.

Summary of Decommissioned Services

  • dispatch-edge-proxy: superseded by Rust wire-guard enclave.
  • redis-pubsub-staging: migrated to internal persistent raft logs.
  • auth-interceptor-v1: discontinued due to non-compliance with mTLS standard.

1. Migration Sequence & Deprecation Timeline

Engineers must ensure all active downstream RPC calls route through the unified envelope adapter. Any direct TCP sockets left open after the target cycle will receive an unconditional TCP RST packet from the gateway supervisor.

"Direct connection persistence across node boundaries has been permanently forbidden to eliminate orphaned transactions during multi-region failovers."
