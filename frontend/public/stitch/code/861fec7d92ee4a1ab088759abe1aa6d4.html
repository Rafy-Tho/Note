#01 Architecture Requirements

When syncing notes across partitioned edge clients, deterministic state convergence is non-negotiable. Standard Operational Transformation (OT) requires a centralized coordination authority, which breaks our offline-first and zero-knowledge invariants. Consequently, every mutation is modeled as an append-only EventLog tracked by causal order via a monotonic VectorClock.

#02 Operational Tenets

  • › Monotonic Clocks: Causality is absolute; local node time skew must not influence conflict arbitration.
  • › Zero Storage Trust: Remote sync brokers operate purely as blind relay nodes without decryption keys.
  • › Deterministic Convergence: Concurrent edits collapse into identical CRDT sets across arbitrary replay topologies.
