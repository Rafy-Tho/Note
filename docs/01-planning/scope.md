# Scope

## In Scope

Authentication, verified email access, password reset, Google and Facebook sign-in, private notes, rich text, autosave, notebooks, tags, favorites, archive, trash, restore, permanent deletion, search, responsive UI, accessibility, and server-side ownership enforcement.

## Out Of Scope

Profile management, general settings, sharing, collaboration, attachments, advanced editor features, version history, templates, offline synchronization, AI features, native mobile applications, Telegram authentication, account deletion, and data export.

## Constraints

Use React/Vite, Node.js/Express, MySQL, REST over HTTPS, npm, Vitest, Supertest, Playwright, Tiptap, ESLint, Prettier, Docker Compose, and the project's mysql2 migration runner. Do not add microservices or infrastructure without a demonstrated MVP need.
