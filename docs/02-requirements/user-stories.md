# User Stories

- As a visitor, I want to register, verify my email, sign in, reset my password, or use a supported provider so I can access my account safely.
- As an authenticated user, I want to create, edit, and autosave notes so I can write without losing work.
- As an authenticated user, I want to organize notes with notebooks, tags, favorites, and archive so I can find them later.
- As an authenticated user, I want to search my notes so I can quickly retrieve information.
- As an authenticated user, I want to trash, restore, and permanently delete notes so I can recover from mistakes safely.
- As a user on desktop or mobile, I want accessible navigation and feedback so the application remains usable across supported browsers.
