# UI Prompt Index

These prompts are instructions for the UI design generator. The official product behavior and scope remain in `../08-ui-ux.md`.

## Prompt Order

1. `01-core-ui-prompt.md` - Global visual system and MVP application UI.
2. `02-password-reset-prompt.md` - Future password-reset extension.

## Extension Rule

Feature prompts must use the core prompt as their visual source of truth. They must not change colors, typography, spacing, layout patterns, or shared component behavior unless explicitly approved.

Only create a feature prompt after the feature is approved in the Requirements and Design documents.
