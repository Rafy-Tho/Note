# Password Reset UI Prompt

Status: Future feature. Not part of the current MVP.

Use `01-core-ui-prompt.md` as the visual source of truth.

When password reset is approved, this prompt will define:

- Forgot-password screen
- Reset request confirmation
- New password form
- Expired or invalid token state
- Reset success state
- Rate-limit and failure states

Do not add password-reset screens to the MVP until the Requirements, Authentication, API, Security, Testing, and Deployment documents are updated.
