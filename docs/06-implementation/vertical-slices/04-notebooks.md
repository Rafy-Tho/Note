# Vertical Slice 04: Notebooks and Organization

## Includes

- Notebook creation, viewing, rename, deletion, and ownership
- Moving notes between owned notebooks or no notebook
- Favorites and archive views
- Archive/unarchive behavior
- Confirmed permanent deletion
- Editor organization controls, workspace dialogs, toasts, responsive drawers, and sidebar counts where they support organization

## Gate

Users can organize owned notes without cross-user access or unintended data loss, with accessible confirmation and feedback.

## Status

In progress. Core organization behavior exists; complete component and browser verification remains pending.
