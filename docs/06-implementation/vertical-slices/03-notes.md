# Vertical Slice 03: Notes and Writing

## Includes

- Blank and populated note creation, list, detail, update, metadata, and ownership
- Active, Archived, and Trashed states
- Tiptap rich text with safe document validation and searchable text
- Debounced autosave, save states, retries, revision conflict protection, and failure retention
- Trash, restore, previous-state recovery, and permanent deletion
- Responsive collection and editor workflows

## Gate

An authenticated user can create, edit, autosave, trash, restore, and safely recover only owned notes without data loss.

## Status

Core notes are complete. Rich text/autosave and trash verification remain in progress.
