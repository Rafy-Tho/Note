# Vertical Slice 05: Tags

## Includes

- Per-user tag creation and uniqueness
- Assigning and removing tags from owned notes
- Tag browsing, rename, deletion, and sidebar management
- Search projection updates after tag changes

## Gate

Users can manage owned tags on owned notes, browse notes by tag, and preserve note data when tags are deleted.

## Status

In progress. Backend and frontend behavior exists; browser verification remains pending.
