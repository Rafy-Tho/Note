# Workflows

## Writing Workflow

```text
Authenticate -> Create or open note -> Edit -> Debounced autosave -> Saved or Save Failed
```

## Organization Workflow

```text
Note -> Notebook and tags -> Favorite or archive -> Search and browse
```

## Recovery Workflow

```text
Active or Archived -> Trash -> Restore previous state when possible
                              -> Permanent deletion after confirmation
```

## Feature Workflow

```text
Requirement -> Database behavior -> API contract -> Frontend behavior
            -> UI states -> Tests -> Acceptance verification -> Documentation
```
