# Agent Workflow

1. Read `AGENTS.md`, `SPEC.md`, the relevant requirement, acceptance criteria, design document, and implementation slice.
2. Inspect the existing source before changing it.
3. Implement the smallest complete vertical change: database, API, frontend, states, and tests.
4. Run relevant formatting, linting, unit, API, integration, and browser checks.
5. Update or add the implementation slice and update `docs/06-implementation/progress.md` with evidence.
6. Check security, ownership, accessibility, responsive behavior, and data-loss risks.
7. Search for stale documentation links before completing the work.
